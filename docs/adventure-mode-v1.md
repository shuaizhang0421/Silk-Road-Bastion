# 行者历练模式设计基线

“行者历练”是与两种守城模式分离的 15–25 分钟动作成长短局。它共享丝路世界、角色、敌人与区域资产，但不继承守城资源、城门、炮塔或驻军经济。

## 一局流程

每章由 7 层随机路线组成：起始营地、普通战斗、事件或精英分支、中段商人三选一、后段高压战斗和章节首领。玩家只选择下一节点，不在一张大地图上来回赶路。完成第三章结算；失败保留图鉴、角色解锁和世界故事，不保留局内装备与等级。

## 三名角色

- 盾刀守卫：格挡、击退、反击，容错最高，适合第一次体验。
- 弩手行者：翻滚、弱点标记、连射，依赖走位与距离控制。
- 机关术士：布置陷阱、范围控制、元素联动，强调预判和组合。

每名角色拥有独立起始装备、六项以上技能强化和专属传奇装备。通用护甲、饰物与少量模块提供跨角色构筑，但不会把三种操作手感抹平。

## 操作与镜头

桌面继续只使用鼠标：点击移动、按住拖动走位、点击敌人锁定、右键闪避、场景技能按钮释放战技。手机使用点击移动、拖动走位、闪避与战技大按钮。镜头比守城更近，角色保持在安全区内，精英前摇和危险范围优先可读。

## 随机与长期性

随机内容包括路线、敌军组合、事件条件、商人物品、装备词条、技能选择和首领奖励。同一种子可复现。局外声望只解锁新装备、事件、角色与难度层级，不永久增加起始伤害。

## 上线门槛

模式入口当前继续显示“后续开放”。达到以下条件后才可解锁：三名角色完整动作、三个章节首领、至少 24 件装备、18 项技能、路线无死路、桌面与触控操作通过、单局节奏与存档恢复通过、资产授权审计通过。
